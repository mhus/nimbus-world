## Item classes (the progression ladder — always define these)

Provide `itemClasses` covering the tier ladder, each with ascending `rank` and a valid `tier`:
`NONE → LEATHER → IRON → STEEL → SILVER → GOLD → MYTHRIL → ADAMANT → ORICHALCUM`.
Each class MUST have a canonical lowercase `name` (id, e.g. "iron" or "bog_iron") AND a themed
display `title` (e.g. "Bog Iron"). Regions may theme the `title` but must keep the rank order.
Tier-bearing items (weapon/armor/tool) reference a class via `itemClass` = the class **`name`**
(not the title), instead of a raw `tier`. Example:
`itemClasses: [{ "name": "bog_iron", "title": "Bog Iron", "rank": 2, "tier": "IRON", "material": "bog_iron_ingot" }]`
and an item `{ "name": "Bog-Iron Spear", "type": "weapon", "itemClass": "bog_iron" }`.
