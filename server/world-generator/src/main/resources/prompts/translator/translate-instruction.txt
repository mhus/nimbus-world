## Output Requirements

1. **Valid JSON**: Output MUST be valid, parseable JSON
2. **Follow Schema**: Strictly follow the Composer Model schema documented above
3. **Complete Structure**: Include all required fields (name, worldId, features, etc.)
4. **Proper Discriminators**: Use correct `featureType` values (e.g., "biome", "village", "river")
5. **Realistic Values**: Use appropriate values for sizes, positions, parameters
6. **No Markdown**: Output ONLY the JSON, no markdown code blocks or additional text

## Output Format

Return ONLY the JSON object. Start with `{` and end with `}`. Do not include:
- Markdown code blocks (no ```json or ```)
- Explanatory text before or after the JSON
- Comments in the JSON

Example output structure:
{
  "name": "Example World",
  "worldId": "example-world",
  "features": [
    ...
  ],
  "continents": [
    ...
  ]
}
